# Pilot boundary

The executable adapter runs the seven existing Dashboard syntax/regression/whitespace checks from an exact Git archive, with no provider connection or application mutation. Python 3.12+ and Node are required. It does not establish browser acceptance, deployed backend authorization, disaster recovery, independent review or production authority.

The validator checks artifact integrity and declared category coverage. EVIDENCE_PRESENT means fields and local artifact hashes satisfy this contract. It does not authenticate source claims, reviewers, CI identity or authority. Production authorization is always false. Attach trusted external CI/review records before any release decision. A locally malicious same-account process and compromised runtimes are outside this offline preflight's trust boundary.

The only implemented runtime adapter is AlphaMind Dashboard. Other skills define reusable procedures and acceptance scenarios; their domain capabilities are not certified or installed in other repositories by this bundle.

Do not publish private cross-repository inventory, the owner's directive or financial/customer data in the public Dashboard repository. The pilot integration includes only the public-safe collector, tests and wrapper.
